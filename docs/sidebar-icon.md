# Пиктограмма статуса империи

Вместо штатного псевдонима `manager` используется отдельный значок
`tm_empire_status`: светлая корона внутри круга с прозрачным фоном.
Регистрация и размеры 128×128 повторяют формат соседних `pi_*` значков.

Исходник: `artwork/empire_status-crown.png`, создан встроенным imagegen.
Выбран простой монохромный круг с трёхзубчатой короной, без текста,
теней, свечения и текстуры, с широкими свободными полями для чтения
на маленькой кнопке. Генерация запрашивала прозрачный фон.

`tools/convert_ui_icon.ps1` уменьшает исходник и записывает DDS RGBA8
в gzip: `assets/textures/ui/player_info/tm_empire_status.gz`.
`libraries/icons.xml` регистрирует самостоятельный идентификатор;
`ui/empire_status.lua` использует его в боковой панели.

Проверены декодирование DDS, прозрачность и вид на синем фоне.
Установленная копия проверяется SHA-256 установщиком. После перезапуска
игры визуальный размер пиктограммы подтверждён пользователем.

После load-18 собственная страница реально открыта через ui-status-08/09,
ресурс tm_empire_status.gz запрошен движком и нет сообщений icon overlap.
Обычные empire/stats страницы также открываются. Визуальный результат
маленькой кнопки подтверждён пользователем после этой пробы:
«её визуальный размер пиктограммы нормальный».
