# Исправление fatal 1079 — 10.10.2026

Симптом: X4 9.00 (611726), `[IDBase::AssignNewID] Failed to assign an ID to the object`, exit 1079 при загрузке тестового save_004.

Причина установлена по журналу: `AutoIDMap::Insert(): ID map is full, no free ID left`. Собственный MD cue `ProjectionWatch` при постоянно истинном условии сбрасывал себя без явной задержки. Повторное выполнение создавало экземпляры `Publish` без продвижения игрового времени; атрибут `checkinterval=5s` не ограничивал этот путь сброса.

Исправление: добавить `delay exact=5s` перед действиями. Собственные self-reset cue дополнительно проверяются `tools/check_md_scheduling.py`; без положительной явной задержки путь с постоянным условием отклоняется. Event-driven ожидания допускаются отдельно. Проверка входит в `tools/validate_md.ps1`.

- `load-14.json`, `load-15.json`, `ui-status-04.json` — повторные загрузки и штатный frame новой вкладки.
- `ui-empire-02.json`, `ui-stats-01.json`, `ui-status-05.json` — переходы между штатными и новой страницами.
- `release-02.json`, `ui-status-06.json` — снятие тестовой должности, неизменный менеджер станции и обновление открытой страницы.
