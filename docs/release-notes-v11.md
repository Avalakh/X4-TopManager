# v11-preview — 14.10.2026

Предварительная сборка TopManager для X4: Foundations 9.00.

## Изменения

- Поддержка обычной UI Extensions and HUD (`ws_3477279743`) вместо beta-версии.
- Завершение работы через разговор с управляющим: новые поручения останавливаются, действующие обязательства проверяются, после очистки модуль управления империей разбирается автоматически.
- Сохранение после завершения можно загрузить без TopManager. Проверено в отдельном игровом сценарии: станция и корабли сохранились.

## Установка и обновление

Скачайте `tm_empire_management-v11.zip` и распакуйте в `X4 Foundations/extensions/`, чтобы появился `extensions/tm_empire_management/content.xml`. Нужны SirNukes Mod Support APIs и обычная UI Extensions and HUD. При переходе с v10-preview отключите beta-версию UI Extensions.

Для удаления сначала завершите работу управляющего через диалог. Дождитесь сообщения о завершении и разборке модуля, сохранитесь в новый слот, выйдите из игры и затем удалите папку мода. Не удаляйте мод, пока он сообщает об ожидании игровых обязательств.

## Статус проверки

Схемы MD, ссылки штатных AI-скриптов и целостность 53 файлов ZIP проверены. Новая UI Extensions и чистое сохранение без мода проверены в X4. В насыщенном сохранении отправленный перевод персонала всё ещё ждёт ответа штатной системы; окончание этого сценария не подтверждено. Полный длительный прогон после изменений v11 ещё не проводился.

Диагностическое расширение и внешние тестовые скрипты в ZIP не входят.
