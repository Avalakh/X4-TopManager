# Диагностический сценарий592–594

governor_roles_setup однократно готовит второй физический module и отдельного
player NPC через нативный character definition/slot. Это бесплатная подготовка
тестового мира; не подтверждает обычное строительство или оплаченный найм.
Marker записывается до создания. Отсутствие доступного slot/сотрудника/модуля
или незавершённое назначение не запускает сценарий.

governor_roles_check проверяет physical container/station/seed и исходного
менеджера. Затем вызывает production RequestAssignment второго сотрудника:
ожидается governor_already_assigned. Только после этого снимает первого,
назначает второго, сверяет registry и независимость менеджера станции,
снимает второго и восстанавливает исходного через те же production функции.
Однократный attempted marker исключает повтор. Неожиданный первый отказ
останавливает дальнейшие действия; неудача после снятия сохраняется unknown.

Это проверка функций, которыми пользуется диалог; ui_dialog_test=false.
2.2 визуальный диалог и save/load этим сценарием не принимаются;2.3 может
приниматься только после живых результатов и проверки единственного Manager.
