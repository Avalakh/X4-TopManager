fixture отдельно от реально оплаченного строителя. Source678 добавляет

deployment, native command и расстояние. Только чтение, без нового dispatch.

Отсутствующий диагностический контракт для2.2: выбор настоящей кнопки
производственного диалога. Primary `common.xsd:start_conversation` запускает
разговор; `ui/core/lua/dialogmenu.lua:leaveDialogMenu` использует
SelectDialogOption, `showDialogMenu` читает GetDialogOption для6 кнопок.
Source679–680 начинает tm_empire_roles с реальным назначенным сотрудником,
читает6 пунктов, выбирает только точный текст снятия либо исходного
station/module. Сохраняет различие choice sent и фактического binding:
после выбора нужен отдельный read игрового Registry. Прямой вызов
RequestAssignment и создание/подмена сотрудника не используются.

Защиты: неизвестная/неактивная/неоднозначная кнопка отклоняется до эффекта;
actor должен принадлежать игроку; один release и один assign на открытие.
Повторная отправка после неизвестного ответа запрещена контроллером.
