# Идентичность сотрудника при сверке обучения — исходник576

ObserveSeminar ранее сверял template/post, навык и расход предмета. Для
нематериализованного сотрудника повторное использование template могло
приписать результат другому человеку. Новая квитанция сохраняет seed до
штатного add_skill/remove_inventory; сверка требует тот же seed.

При изменении личности результат остаётся unknown с отдельной русской
причиной во вкладке. Повторного расхода/обучения или восстановления предмета
не производится. Старые квитанции не получают выдуманный исходный seed.
Штатный механизм семинара и уже принятая проверка4.3 сохранены.

управляющего также PASS в этой порции. Они проверяют соответствующие
контракты, но не доказывают игровой сценарий смены личности при обучении.
