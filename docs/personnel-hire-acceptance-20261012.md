# Приёмка4.1 — вакансии и реальный платный наём

Проверены указанные в задаче4.1 границы, совместно с ранее принятыми
проверками отдельных должностей. Повторять внутренние алгоритмы штатного
найма для каждого controlpost не требуется.

- `personnel-integration-acceptance-20261012.md`: пустой собственный корабль
  получил prerequisite ship_pilot_arrival_required. Обычный кадровый tick
  самостоятельно выбрал известного реального кандидата, списал478960Cr,
  получил того же сотрудника/seed, intransit0/scheduled0/podnull. Второй
  автономный сценарий read671–672 подтвердил платный наём135480Cr.
- Тот же документ и реальные personnel scans показывают отсутствие
  доступного кандидата: no_available_employee_in_current_batch /
  known_hireable_actor_unavailable. Наём и подмена сотрудника не выполняются.
  В текущем save012 scan свободного station manager post сохраняет этот
  отказ; это реальная недоступность кандидата, а не фиктивный успех.
- `source-batch-786-20261012.md` / fixtures786.json: существующий
  personnel_hire_fixture проверяет реальный production payment module.
  Недостаток денег, смена цены/разрешения, helm/manual, потеря цели и
  unknown/replay не списывают деньги повторно. Наём получает цену обычного
  кандидата, не создаёт бесплатного NPC в production.
- `governor-singleton-acceptance-20261012.md`: реальная отдельная должность
  governor, второй активный отклонён; снятие/смена не изменили station manager.
  В source кадровый поиск использует штатные vacant controlposts;
  governor хранится отдельной module-bound ролью и защищён от перераспределения.
- `station-save012-load-20261012.json`: дополнительный платный hire559840Cr
  сохранён как observed, тот же seed-7711824739669823977, passed1 после
  native save/load. Этот дополнительный сценарий запускался диагностикой;
  доказательство самостоятельного выбора дают предыдущие autonomous ticks.

Это принимает4.1. Перемещение/недоступный маршрут4.2 и общий приоритет3.7
остаются отдельными открытыми задачами. Диагностические кандидаты — подготовка
условий; создание сотрудника в production не подменялось диагностикой.
