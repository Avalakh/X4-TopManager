# Модуль управления империей

Публичный исходный код мода для X4 9.00. Текущий пакет для скачивания —
`dist/tm_empire_management-v10.zip`, SHA-256
`f8c66b4f63c409541843f8ff70459d4c13b2a14eb6f054e229b53a8da1caa8ea`.
Это тестовый кандидат: короткие игровые проверки набора и распределения персонала
прошли, но двухчасовой общий прогон именно v10 не завершён. Базовые функции
раннего выпуска ранее прошли два двухчасовых прогона.

Подробности новых проверок — в `docs/captain-staffing-v10-acceptance-20261014.md`;
состав и SHA пакета — в `dist/tm_empire_management-v10.manifest.json`.
Мод добавляет постройку управляющего модуля, отдельную должность управляющего
империей, вкладку статуса и автоматические экономические, строительные,
кадровые и военные действия на основе адаптированных штатных механизмов X4.
Управляющий также подбирает безопасную работу простаивающим кораблям.

Мод работает внутри игры. Внешнее приложение и Extension Options не нужны.
Нужны SirNukes Mod Support APIs и kuertee UI Extensions and HUD, указанные
в `content.xml`. Диагностическое расширение используется отдельно для испытаний
и в пользовательскую поставку не входит.

## Установка выпуска

При закрытой X4 распакуйте `dist/tm_empire_management-v10.zip` в папку
`X4 Foundations/extensions/`. Внутри архива уже есть каталог
`tm_empire_management`, поэтому результатом должен быть файл
`extensions/tm_empire_management/content.xml`. Включите мод в меню расширений
и загрузите сохранение, созданное с нужными зависимостями. Отдельное тестовое
расширение `tm_empire_diagnostics` для работы мода не требуется.

## Установка из исходников

При закрытой игре выполните из каталога клонированного репозитория:

```powershell
python tools/install_mod.py --game "D:/Games/SteamLibrary/steamapps/common/X4 Foundations" --include-adapted
```

Параметр `--include-adapted` включает копию штатного управляющего. Установщик
проверяет SHA и записывает мод в `extensions/tm_empire_management`. Python нужен
только установщику; во время игры управляющий его не использует.

В Steam достаточно обычного запуска: дополнительные параметры из текущих
настроек Steam повторно передавать не нужно.

Полный архив для переноса на другой компьютер собирается из того же состава:

```powershell
python tools/package_mod.py --output dist/tm_empire_management-candidate.zip
```

Распакуйте папку `tm_empire_management` из архива в `extensions` при закрытой
игре. Установите указанные выше зависимости. Рядом с архивом создаётся manifest
с SHA каждого файла и самого архива. До окончания игровой приёмки это
испытательный пакет; диагностическое расширение в архив не включено.

## Чертёж, модуль и сотрудник

1. Получите требуемый аргонский ранг и строительную лицензию обычным игровым
   способом. Если требуется церемония у представителя, завершите её.
2. Купите чертёж «Модуль управления империей» у представителя Аргонской Федерации.
   Стоимость и доступность определяются игрой.
3. Добавьте модуль в план своей станции и дождитесь окончания строительства.
   Он сохраняет штатные свойства исходного административного центра.
4. Выберите отдельного собственного сотрудника без занятой командной должности.
   Менеджер станции продолжает работать менеджером станции.
5. В разговоре с сотрудником откройте дополнительные команды и пункт
   «Управление империей…», затем выберите действующий модуль своей станции.
   Если нужен перевод, назначение завершается после подтверждённого прибытия.

Одновременно работает один управляющий империей. Для смены сотрудника сначала
освободите текущую должность через его диалог, затем назначьте другого.

## Статус и управление

В PlayerInfoMenu вкладка «Статус империи» располагается после вкладки империи
и перед статистикой. Она показывает управляющего, собственность, поручения,
текущий статус станций, их потребности и причины ожидания. Для производства
видны работающие модули, ожидание ресурсов/склада и паузы; отдельно показаны
потребности бюджета, добывающих и торговых кораблей. Оценка сотрудников и история для неё
не собираются. Отправленный приказ ещё не означает
выполнение; неизвестный исход удерживает повтор этого действия.

Назначение сотрудника активирует управляющего без отдельных переключателей
доменных функций. Он использует адаптированные штатные механизмы с реальными
деньгами, ресурсами и ограничениями игрока. Корабль исключается, когда игрок
лично находится за штурвалом. Нахождение игрока пассажиром само по себе корабль
не исключает. Ручные и приоритетные поручения учитываются перед новым эффектом.

Управляющий может назначать работу простаивающим
кораблям: с бессрочным ожиданием, завершённым «Стыковаться и ждать» или
завершённым «Лететь и ждать». Полёт к точке, отступление, ремонт, торговля,
служебные ожидания и очередь рабочих задач сохраняются. Обновление также
сохраняет прокрутку вкладки. В коротком игровом прогоне подтверждены
переназначение простаивающего «Дротика», сохранение рабочих приказов других
кораблей и прокрутки после обновления. Отдельная проверка завершённого
«Лететь и ждать» остаётся открытой.

Если для свободного корабля сейчас нет более важной штатной потребности,
управляющий даёт ему ограниченную местную задачу: торговому судну — автоторговлю,
оснащённому добытчику — автодобычу, малому разведчику — разведку. Он проверяет
капитана, оборудование, известность и безопасность сектора, повреждения и
недавнее нападение. Вкладка показывает причину, по которой неподходящий корабль
ожидает. Запасное поручение управляющий может снять ради более важной задачи;
перед новой ролью он дожидается прекращения собственного старого приказа.
Ручные, приоритетные и неизвестные приказы он сохраняет. В спорный сектор
корабль ради запасной задачи не отправляется.

Статус станции берётся из текущих штатных данных. Если свежих данных нет,
показывается неизвестность. Менеджер станции продолжает обычную работу;
управляющий империей рассматривает потребности в общем стратегическом цикле.

## Остановка и откат

Чтобы остановить новые решения, используйте «Освободить должность управляющего
империей». Утрата действующего модуля или сотрудника также останавливает новые
эффекты. Уже оплаченные заказы и отправленные переводы остаются игровыми
обязательствами; освобождение должности не возвращает их стоимость и не
подменяет подтверждение исполнения.

Полный откат установки предполагает возврат к сохранению до появления объектов
этого мода и отключение только `tm_empire_management`. Простое удаление расширения
из сохранения с построенным модулем не квалифицировано как безопасный откат.
Чужие расширения и базовые файлы игры установщик не изменяет.
