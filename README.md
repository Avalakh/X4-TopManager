# Модуль управления империей для X4: Foundations

Постройте административный модуль, назначьте отдельного управляющего — и ваша империя начнёт решать повседневные задачи через игровые механизмы X4. Управляющий занимается развитием, экономикой, флотом и персоналом, а вы видите его работу во вкладке **«Статус империи»**.

Сборке требуется тестовая версия UI Extensions and HUD, страница которой сейчас недоступна в Steam (подробнее — в требованиях ниже). Для важного прохождения сохраните резервную копию перед установкой.

## Что умеет управляющий

- **Развивает империю:** использует адаптированные штатные механизмы X4 для экономики, строительства, снабжения и обороны.
- **Работает с флотом:** подбирает задачи свободным кораблям; торговому судну может назначить автоторговлю, оснащённому добытчику — автодобычу, малому разведчику — разведку. Учитывает капитана, оснащение и безопасность района.
- **Занимается персоналом:** нанимает и перемещает сотрудников, в том числе заполняет вакансии капитанов. При необходимости может заказать экипаж через обслуживание на верфи или доке оборудования.
- **Показывает причины решений:** во вкладке статуса видны собственность, текущие поручения, работа станций, их потребности и причины ожидания. Менеджеры станций продолжают управлять своими станциями; отдельные оценки их эффективности мод не ведёт.

Ручные и приоритетные приказы игрока сохраняют преимущество. Управляющий не переназначает корабль, когда игрок лично сидит за его штурвалом; присутствие игрока пассажиром этому не мешает. Одновременно действует **один** управляющий империей.

## Установка

Нужны **X4: Foundations 9.00** и два расширения:

- [SirNukes Mod Support APIs](https://steamcommunity.com/sharedfiles/filedetails/?id=2042901274)
- **kuertee UI Extensions and HUD [BETA] 9.00**, идентификатор `ws_3724217776`. Именно с этой сборкой проверен мод. Её страница Steam сейчас недоступна; обычная [UI Extensions and HUD](https://steamcommunity.com/sharedfiles/filedetails/?id=3477279743) имеет другой идентификатор и пока не подтверждена как замена.

1. Установите зависимости и закройте игру.
2. Скачайте **`tm_empire_management-v10.zip`** со страницы [релиза](https://github.com/Avalakh/X4-TopManager/releases/tag/v10-preview). Архивы *Source code* на GitHub не являются готовым модом.
3. Распакуйте ZIP в `X4 Foundations/extensions/`. В итоге должен существовать файл `X4 Foundations/extensions/tm_empire_management/content.xml`.
4. Включите расширение в меню игры и загрузите сохранение.

Мод работает внутри X4; отдельное приложение для его использования не требуется.

## Первые шаги в игре

1. Получите необходимый ранг и строительную лицензию Аргонской Федерации. Купите у её представителя чертёж **«Модуль управления империей»**.
2. Постройте модуль на своей станции. Он создан на основе аргонского административного центра и сохраняет его штатные административные свойства.
3. Выберите собственного сотрудника для новой должности. В разговоре откройте дополнительные команды → **«Управление империей…»** и укажите построенный модуль. Управляющий станции остаётся на своей должности.
4. Откройте информацию об игроке → **«Статус империи»**. Вкладка находится между вкладкой империи и статистикой. Здесь можно проверить, чем занят управляющий и чего не хватает станциям или кораблям.

Если сотрудник находится в другом месте, назначение завершится после его прибытия. Отдельно включать направления работы не нужно. Чтобы сменить управляющего, сначала освободите должность через его диалог.

## Важное о сохранениях

Освобождение должности останавливает **новые** решения управляющего, но уже оплаченные заказы и отправленные переводы остаются действующими игровыми обязательствами. Для полного удаления мода используйте сохранение, сделанное **до** постройки его объектов: безопасное удаление расширения из сохранения с построенным модулем пока не подтверждено.
